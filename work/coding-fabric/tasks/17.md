# Task 17: Conformance harnesses scaffolding (4 harnesses)

## Required Skills
Before starting, load: /skill:playwright-pro

## Description
Scaffold the four conformance harnesses gated by `task_type` in PRs (T16):
byte-equivalence, MCP-compat, WASM-browser, full-mode. Each harness has a Makefile
entrypoint, a tests directory, and an Action wrapper. Real fixtures depend on actual
mnemonic-core/mcp/wasm code which isn't available in this repo — harnesses scaffold the
structure and document the fixture-injection contract. Anchors user-spec AC17–AC22,
tech-spec D15, §5.

## What to do
- `fabric/harnesses/byte-equivalence/` — Rust/TS/WASM serializer round-trip stub against a placeholder fixture corpus; Makefile orchestrates
- `fabric/harnesses/mcp-compat/` — reference MCP client driver + golden trace format
- `fabric/harnesses/wasm-browser/` — Playwright config + a stub test that asserts WASM serializer matches Rust reference
- `fabric/harnesses/full-mode/` — Solana devnet round-trip + Arweave testnet round-trip + independent-verifier scaffolding
- `fabric/harnesses/actions/{byte-equivalence,mcp-compat,wasm-browser,full-mode}/action.yml` — composite Actions
- Each harness has a `README.md` describing how to drop in real fixtures

## TDD Anchor
- `tests/test_byte_equivalence_fixture_mismatch` — mutating fixture flags failure
- `tests/test_mcp_compat_recorded_trace` — golden trace mismatch flags failure
- `tests/test_wasm_browser_runs_headless` — Playwright sanity
- `tests/test_full_mode_devnet_roundtrip_stub` — devnet RPC mocked, round-trip logic verified
- `tests/test_dispatch_by_task_type` — pr-conformance dispatcher picks right harness

## Details
**Files:**
- `fabric/harnesses/{byte-equivalence,mcp-compat,wasm-browser,full-mode}/{Makefile,README.md,fixtures/,tests/}`
- `fabric/harnesses/actions/*/action.yml`

**Edge cases:**
- Solana devnet rate-limit — harness retries with backoff, max 3
- Arweave testnet down — surface `infra_unavailable` rather than fail
- Playwright flake on shared CI — pin version, `--retry=2`

**Implementation hints:**
- Keep stub corpora small (< 100 KB each)
- Independent verifier is a separate small binary invoked via subprocess (clean trust boundary)
- Document the fixture-injection contract so each protocol repo can supply its real corpus
