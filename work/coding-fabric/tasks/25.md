- Deliberate-break rollback fails ≤ 5 min → workflow aborts, restores manually, opens critical remediation task, does NOT sign attestation
- Recursive self-merge lands a buggy state → last-known-good holds; revert via safe-mode
- Telegram MCP / Playwright MCP unavailable in CI runner → workflow fails with explicit "MCP tool unavailable, retry"

**Implementation hints:**
- Use Telegram MCP via the bot's tailnet API endpoint
- Use Playwright MCP via headless mode in CI runner (tailnet SSH tunnel to Kaneo)
- Each AVP step is its own JSON-emitting sub-step; aggregate at end
- The recursive self-merge PR's content can be a trivial watchdog text-update (low risk, real change)
