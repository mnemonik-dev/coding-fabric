# Task 01: OpenTofu module for Hetzner VM + volume + firewall

## Required Skills
Before starting, load: /skill:terraform-master (works for OpenTofu — same syntax).

## Description
Provision the single Hetzner Cloud VM that hosts the entire fabric, plus an attached
200 GB volume and a firewall that blocks all public traffic except Tailscale handshake.
This is the cold-start IaC layer; everything else (Ansible roles, fabric services) runs
on top. Anchors tech-spec D1, D3, user-spec AC1, AC5, AC32, §6.

## What to do
- Write `infrastructure/tofu/hetzner/main.tf`:
  - `hcloud_server` — type `ccx33`, location `fsn1`, image `ubuntu-24.04`, user_data
    cloud-init with operator SSH key
  - `hcloud_volume` — 200 GB, `fsn1`, format `ext4`, automount
  - `hcloud_volume_attachment` — attach volume to server
  - `hcloud_firewall` — allow inbound UDP/41641 (Tailscale derp/direct) from `0.0.0.0/0`; deny everything else inbound
  - `hcloud_firewall_attachment`
- `variables.tf` — `hcloud_token` (from env `HCLOUD_TOKEN`), `operator_ssh_pubkey`
- `outputs.tf` — `vm_ipv4`, `vm_ipv6`, `volume_device`
- `versions.tf` — pin `hashicorp/hcloud` provider, OpenTofu >= 1.6

## TDD Anchor
