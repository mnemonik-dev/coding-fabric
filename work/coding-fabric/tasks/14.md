# Task 14: `fabric/integrations/swarm-bridge.py` (`/do-feature` → ruflo swarm)

## Required Skills
Before starting, load: /skill:python-alchemist

## Description
Adapter so molyanov's `/do-feature` dispatches through ruflo swarm MCP (`swarm_init`,
`agent_spawn`) with per-task cwd resolved against workspace-manager (T08). Each spawned
agent operates in an isolated worktree. Anchors user-spec AC9, tech-spec D12.

## What to do
- `fabric/integrations/swarm-bridge.py`:
  - on receiving a feature plan: call `swarm_init` once
  - for each wave: for each task, lease a worktree via `POST /worktree`, then
    `agent_spawn` with `cwd=<resolved>` and task brief
  - context-manager pattern for worktree lifetime (auto `DELETE` on exit)
  - cleanup on partial failure: successful spawns still get DELETE
- modify `~/.fabric/molyanov/skills/feature-execution/SKILL.md` to invoke the bridge
