# Task 18: `fabric/watchdog/` (9 alert classes + `/turn-into-task`)

## Required Skills
Before starting, load: /skill:python-alchemist

## Description
Python service running every 5 minutes under systemd timer. Checks 9 alert classes,
posts to `ops` Telegram topic, supports `/turn-into-task <alert_id>` bot command that
creates a Kaneo card from an alert. Operational toil becomes work items. Anchors
user-spec AC29–AC32, tech-spec D19, D20.

## What to do
- `fabric/watchdog/checks/*.py` — one module per alert class:
  1. `orphaned_worktrees` — on-disk worktrees not in workspace-manager state
  2. `hung_tmux` — sessions idle > 12h
  3. `solana_rpc` — devnet RPC unresponsive
  4. `irys_balance` — testnet balance below threshold
  5. `stale_swarms` — ruflo swarms past TTL
  6. `disk_pressure` — 75/85/90% of 50 GB budget
  7. `master_drift` — local master HEAD diverged from origin
  8. `stale_prs` — open > 7 days
  9. `failed_attestation` — Mnemonic MCP queue contains failures
  10. `stale_lkg` — `last-known-good` tag > 7 days
- `fabric/watchdog/scheduler.py` — runs all checks; aggregates and posts batch to ops
- `fabric/watchdog/turn_into_task.py` — Telegram bot command handler
- `fabric/watchdog/state/alerts.json` — alert id cache (TTL 24h)
- systemd timer + service templates packaged via `fabric-services` Ansible role
- All log emissions through sanitizer (T07)
