# Task 10: /do-feature dispatches to ruflo swarm with per-task cwd injection

## Required Skills
Before starting, load: /skill:python-alchemist

## Description
Make the molyanov `/do-feature` slash command route work through ruflo's swarm MCP tools
(`swarm_init`, `agent_spawn`) and inject each agent's `cwd` from workspace-manager so
every spawned agent operates inside an isolated worktree. Anchors user-spec AC9,
tech-spec §3 D6, §4 Wave 4.

## What to do
- Implement a thin Python adapter `swarm-bridge.py` that:
  1. Receives the feature plan (wave + task list).
  2. Calls ruflo's `swarm_init` MCP tool to set up swarm topology.
  3. For each agent in a wave: calls `POST /worktree` to mint a per-task worktree id,
     then calls `agent_spawn` with `cwd=<resolved-path>` and the task brief.
  4. Tears down worktrees on swarm completion.
- Modify the molyanov `feature-execution` skill to call this adapter instead of spawning
  agents directly.
- Surface swarm-level errors back to the originating topic with a sanitized excerpt.
