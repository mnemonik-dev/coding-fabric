# Task 13: Conformance harnesses (byte-equivalence, MCP-compat, WASM-browser, full-mode)

## Required Skills
Before starting, load: /skill:playwright-pro

## Description
Implement four conformance harnesses runnable as gate jobs, each tied to a `task_type`.
These harnesses enforce protocol-level invariants that no unit test by itself can prove.
Anchors user-spec AC17–AC22, tech-spec §3 D9, §4 Wave 5, §5.

## What to do
- **byte-equivalence/** — Rust ↔ WASM ↔ TypeScript serializers produce identical bytes for
  a fixture corpus of CBOR/schema artefacts. Failure: mismatch report listing first
  divergence offset.
- **mcp-compat/** — runs a reference MCP client (recorded golden traces) against the
  current `mnemonic-mcp` build. Failure: a tool-call divergence is highlighted.
- **wasm-browser/** — Playwright-driven headless-Chromium test that loads
  `mnemonic-wasm` bindings and asserts byte-equivalence with the Rust reference for the
  same fixture corpus.
- **full-mode/** — Solana devnet round-trip (`mnemonic_sign_memory` → fetch → verify) and
  Arweave testnet round-trip (`upload → fetch → reconstruct via independent verifier`).
- Wire each harness as a reusable GitHub Action so per-repo `pr-conformance.yml`
  (Task 12) can dispatch the right harness based on `task_type`.

## TDD Anchor
- `tests/test_byte_equivalence_fixture_mismatch.py` — mutating one byte in fixture flags failure
- `tests/test_mcp_compat_recorded_trace.py` — golden trace mismatch flags failure
- `tests/test_wasm_browser_matches_rust.py` — Rust and WASM output identical for known input
- `tests/test_full_mode_devnet_roundtrip.py` — signed memory recoverable from devnet
- `tests/test_full_mode_arweave_independent_verifier.py` — independent verifier reconstructs from Arweave
- `tests/test_dispatch_by_task_type.py` — `pr-conformance` dispatcher picks right harness

## Details
**Files:**
- `~/.fabric/harnesses/byte-equivalence/{Makefile,rust/,ts/,wasm/,fixtures/,tests/}`
- `~/.fabric/harnesses/mcp-compat/{Makefile,golden/,client.py,tests/}`
- `~/.fabric/harnesses/wasm-browser/{playwright.config.ts,tests/}`
- `~/.fabric/harnesses/full-mode/{Makefile,devnet_roundtrip.py,arweave_roundtrip.py,independent_verifier.py,tests/}`
- `~/.fabric/harnesses/actions/{byte-equivalence,mcp-compat,wasm-browser,full-mode}/action.yml`

**Dependencies:** Task 03 (master repos cloned; harnesses reference fixtures from them).

**Edge cases:**
- Solana devnet rate-limiting — harness must retry with backoff, max 3 attempts.
- Arweave testnet availability — guard with a timeout; if testnet is down, surface
  `infra_unavailable` rather than fail.
- Headless browser flake on shared CI — pin Playwright version and use `--retry=2`.

**Implementation hints:**
- Keep fixture corpora small (under 100 KB each) and check them into the harness repo.
- Independent verifier should be a separate small binary invoked via subprocess to keep
  its trust boundary clean.
