# Task 15: last-known-good auto-update + fabric-safe-mode rollback + smoke gate

## Required Skills
Before starting, load: /skill:github-actions-pro

## Description
The three pieces that make recursive self-hosting safe:
1. `last-known-good` git tag advanced after every successful non-loop task.
2. `fabric-safe-mode rollback` script that returns the fabric to the last-known-good state.
3. Smoke gate — a 15-minute end-to-end docs task that must pass before any `mnemonic-loop`
   PR is allowed to merge.
Anchors user-spec AC33–AC37, tech-spec §3 D15, D16, D17, §4 Wave 6 T6.2, §8 TR5.

## What to do
- **last-known-good auto-update:** add a post-success hook on do-task completion that
  fast-forwards the `last-known-good` tag in the `mnemonic-loop` repo to HEAD when the
  completed task is NOT in `mnemonic-loop`. Push tag to remote.
- **fabric-safe-mode rollback script:** bash script invoked via SSH that:
  1. Stops fabric services (workspace-manager, watchdog, mnemonic-mcp, telegram-ai-agent).
  2. `git checkout` `last-known-good` in `mnemonic-loop` worktree on VM.
  3. Rebuild from that state (re-install configs, restart services).
  4. POST a banner to ops topic via Telegram bot.
- **Smoke gate** for `mnemonic-loop` PRs:
  - GitHub Action that on PR open/update spins up a candidate fabric (docker-compose
    equivalent), drives a trivial docs-task end-to-end, hard-budgets 15 minutes.
  - Sets a required status check; merge blocked on failure.

## Details
**Files:**
- `~/.fabric/safe-mode/{rollback.sh,last-known-good.sh}`
- `/usr/local/bin/fabric-safe-mode` — symlink to `rollback.sh` for SSH invocation
- `~/code/mnemonic-masters/mnemonic-loop/.github/workflows/smoke-gate.yml`
- `~/code/mnemonic-masters/mnemonic-loop/.github/smoke-gate/{run.sh,docs-task.md,Dockerfile,tests/}`
- molyanov `do-task` post-success hook → `~/.fabric/safe-mode/last-known-good.sh`

**Dependencies:** Task 02 (Telegram bot to post banner), Task 14 (watchdog might fire during a deliberate-break test — ops topic is wired).

**Edge cases:**
- Rebuild fails during rollback (e.g., package install fails) — script must abort and
  post a high-severity ops alert; do not leave services half-stopped.
- Concurrent rollback attempts — file-lock at `/var/lock/fabric-safe-mode`.
- Smoke-gate CI runner caches: invalidate on changes to fabric init files.

**Implementation hints:**
- `last-known-good` tag is annotated, signed by Mnemonic if available.
- Smoke-gate's docs-task is the exact same task used in Task 09 (e2e smoke) — keep one source.
- Keep `rollback.sh` under 200 lines; lift complex steps into idempotent sub-scripts.
