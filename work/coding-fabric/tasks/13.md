# Task 13: CI job `e2e-smoke.yml` (post-deploy end-to-end)

## Required Skills
Before starting, load: /skill:github-actions-pro

## Description
GitHub Actions workflow that runs after a `deploy-fabric.yml` (T24) completes:
SSH into the freshly-deployed VM (via Tailscale GitHub Action), drive one representative
docs feature through the full pipeline, assert the 5-node DAG, assert worktree cleanup.
Replaces v0.1.1 Task 09 (manual e2e). Anchors user-spec §8.3, AC1–AC16, tech-spec §2.3,
§5.

## What to do
- `.github/workflows/e2e-smoke.yml`:
  - trigger: `workflow_call` from `deploy-fabric.yml`; also `workflow_dispatch`
  - steps: Tailscale up via `tailscale/github-action`; SSH to `op@mnemonic-fabric`;
    invoke a fixed smoke-test script `scripts/e2e/smoke.sh` on VM; collect output
  - smoke.sh on VM: triggers a docs-typo PR via Telegram bot (synthetic message), polls
    Mnemonic MCP every 30s for 5-node DAG (timeout 20 min), asserts cleanup
  - on success: comment on triggering commit; on failure: post detailed log to ops topic

## Acceptance Criteria
- [ ] Workflow valid YAML; passes `actionlint`
- [ ] Triggered manually against a real VM: produces a real 5-node DAG and reports success
- [ ] Failure modes (timeout, partial DAG) reported clearly; workflow exits non-zero
