# Task 05: Ansible role `telegram-init`

## Required Skills
Before starting, load: /skill:ansible-automation

## Description
Create (or update) the Telegram forum supergroup and its eight topics via the Bot API,
fully idempotent. The bot itself must exist (one-time @BotFather step in bootstrap
checklist); this role takes the bot token from sops-encrypted secrets and idempotently
ensures the chat structure matches the canonical list. Anchors tech-spec §2.3 role 5,
user-spec §4.1, AC1–AC3.

## What to do
- `roles/telegram-init/tasks/main.yml`:
  - read `TELEGRAM_BOT_TOKEN`, `TELEGRAM_FORUM_CHAT_ID` from sops
  - call `getForumTopicIconStickers` then `getChatAdministrators` to verify bot has the right perms
  - for each of 8 topics (`core`, `mcp`, `wasm`, `demo-client`, `docs`, `loop`, `protocol-qa`, `ops`):
    - `getForumTopics` (paginated) to check existing
    - if missing → `createForumTopic`; capture `message_thread_id`
    - update `infrastructure/ansible/inventory/telegram-topics.yml` with name → thread_id mapping (committed back; safe because IDs don't rotate)
- Healthcheck: bot can post to each topic

## Acceptance Criteria
- [ ] All eight topics exist after first run; identical IDs after second run
- [ ] `infrastructure/ansible/inventory/telegram-topics.yml` updated and reflects current chat
- [ ] Bot can post to each topic (verified by test send + delete)
- [ ] `ansible-lint` passes
