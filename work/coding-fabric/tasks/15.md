# Task 15: `fabric/molyanov/validators/` (delegation to ruflo plugins)

## Required Skills
Before starting, load: /skill:python-alchemist

## Description
Three thin Python wrappers: molyanov `skeptic` → ruflo `jujutsu`,
`security-auditor` → ruflo `security-audit`, `post-deploy-qa` → ruflo `browser`.
Reports stay in molyanov format; delegation is transparent. Anchors user-spec AC10,
tech-spec D13.

## What to do
- For each wrapper:
  - read molyanov-format input
  - invoke ruflo plugin via CLI/MCP
  - normalise output back to molyanov JSON schema
  - attach `delegated_to` field naming the plugin
- Shared normaliser in `_common.py`
- `--dry-run` flag prints which plugin would be invoked
