# Task 19: `fabric/safe-mode/` + Ansible rollback playbook + smoke-gate workflow

## Required Skills
Before starting, load: /skill:github-actions-pro

## Description
Three pieces that make recursive self-hosting safe:
1. `last-known-good` tag auto-update after every successful non-loop task
2. Ansible-idempotent `safe-mode-rollback.yml` playbook invoked over SSH
3. Smoke-gate CI workflow — 15-min docs task end-to-end on a candidate fabric before
   any `mnemonic-loop` PR can merge
Anchors user-spec AC33–AC37, tech-spec D21, D22, D23, §8 TR7.

## What to do
- `fabric/safe-mode/last-known-good.sh` — post-success hook called by do-task; tags `mnemonic-loop` HEAD as `last-known-good` and pushes
- `infrastructure/ansible/playbooks/safe-mode-rollback.yml`:
  - stop fabric services
  - checkout `last-known-good` in `mnemonic-loop` master clone
  - re-run `deploy.yml` for fabric services only (skip OpenTofu, base, vaultwarden, kaneo — those don't change in a loop revert)
  - post ops banner
- `.github/workflows/smoke-gate.yml` (for mnemonic-loop repo):
  - required check on PRs touching loop
  - spins up candidate fabric in CI (docker-compose-based ephemeral)
  - runs a trivial docs-task end-to-end with 15-min hard budget
  - blocks merge on failure

## Details

- `.github/workflows/smoke-gate.yml`

**Edge cases:**
- Rollback fails (e.g., package install error) — abort; high-severity ops alert; don't leave half-stopped
- Concurrent rollback — file lock at `/var/lock/fabric-safe-mode`
- Smoke-gate CI runner caches stale — invalidate on changes to fabric init files

**Implementation hints:**
- Smoke-gate docs-task is the same one used in T13 e2e smoke — keep one source
- `last-known-good` tag is annotated, signed by Mnemonic if available
- Ansible's idempotency is the rollback's correctness guarantee — no bespoke bash rollback
