# Task 24: CI workflow `deploy-fabric.yml` (cold-start bootstrap)

## Required Skills
Before starting, load: /skill:github-actions-pro

## Description
The cold-start CI workflow that runs `tofu apply` then `ansible-playbook deploy.yml`,
producing the entire fabric on a fresh Hetzner VM. Triggers: tag push `fabric-v*` or
manual `workflow_dispatch`. After successful deploy, calls `e2e-smoke.yml` (T13). After
first bootstrap, subsequent fabric updates flow through the fabric itself (recursive
self-hosting via T19 smoke-gate); this workflow remains the emergency cold-start path.
Anchors user-spec AC33, tech-spec D5, D7, D31.

## What to do
- `.github/workflows/deploy-fabric.yml`:
  - jobs: `tofu-plan` (always), `tofu-apply` (conditional on dispatch input or tag),
    `ansible-deploy`, `e2e-smoke` (invokes T13 workflow), `attest` (signs deploy attestation via Mnemonic MCP)
  - secrets: `HCLOUD_TOKEN`, `TAILSCALE_AUTH_KEY`, `SOPS_AGE_KEY`,
    `VAULTWARDEN_INITIAL_ADMIN_PASSWORD`, `TELEGRAM_BOT_TOKEN`, `SOLANA_DEVNET_KEYPAIR`,
    `IRYS_TESTNET_PRIVATE_KEY`, `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, `GITHUB_DEPLOY_PAT`
  - state: store OpenTofu state as GH Actions artifact, encrypted with sops/age (D31)
  - on failure: post diagnostic to ops topic via curl + Telegram bot token
- `infrastructure/ansible/playbooks/deploy.yml` — orchestrates roles in order:
  base → tailscale → vaultwarden → kaneo → telegram-init → restic-backups → ruflo →
  molyanov → mnemonic-mcp → fabric-services → mnemonic-tg-bridge
- `infrastructure/ansible/inventory/hosts.yml.j2` — populated from tofu outputs
- `infrastructure/scripts/bootstrap.sh` — local helper to seed sops/age key, encrypt secrets

**Edge cases:**
- Hetzner API rate limit during apply — Tofu provider retries; on persistent → fail with clean error
- Tailscale auth-key expired mid-run — workflow exits with actionable error, no half-deploy
- State artifact upload failure — abort before declaring success; previous state preserved

**Implementation hints:**
- Use `hashicorp/setup-terraform` action but point to OpenTofu (`opentofu/setup-opentofu`)
- Tailscale GitHub Action: `tailscale/github-action@v2` with ephemeral key
- For first-ever run, OpenTofu state artifact doesn't exist — handle gracefully
- After deploy, trigger T13 e2e-smoke as a `workflow_call`
