# Task 19: Pre-deploy QA

## Required Skills
Before starting, load: /skill:pre-deploy-qa

## Description
Acceptance testing methodology: run the entire test suite, verify every acceptance
criterion from `user-spec.md` and `tech-spec.md`, and produce a structured JSON report.
This task does NOT require the live environment — it operates against the staging fabric
or local dev fabric. Anchors tech-spec §4 Wave 8.

## What to do
- Run all unit and integration test suites for every component delivered by Tasks 01–15.
- Walk through each user-spec AC (42) and tech-spec AC and:
  - Mark COVERED if a passing test exists.
  - Mark MANUAL if a documented manual step exists and was executed.
  - Mark DEFERRED if it requires the live VM and will be picked up by Task 21 post-deploy.
- Produce `work/coding-fabric/logs/tasks/pre-deploy-qa.json` with overall PASS/FAIL plus
  per-AC verdict.
- Trigger the Mnemonic MCP `pre-deploy.sh` hook (Task 08) on success → creates the
  pre-deploy receipt with parent = task receipts.

## Acceptance Criteria
- [ ] All unit/integration suites run; results captured.
- [ ] Every AC (user-spec + tech-spec) has a verdict.
- [ ] Mnemonic pre-deploy attestation created on success.
- [ ] Report indicates which ACs are deferred to post-deploy.

## Context Files
- [tech-spec.md](../tech-spec.md) — §4 Wave 8, §5, §6 AVP
- [user-spec.md](../user-spec.md) — all ACs

## Verification Steps
**Automated:**
- `jq '.overall' work/coding-fabric/logs/tasks/pre-deploy-qa.json` returns `"pass"`
- `mnemonic_recall --feature=coding-fabric --node=pre-deploy` returns a receipt with the correct parent chain

## Details
**Files:** read all; write `logs/tasks/pre-deploy-qa.json`; call Task 08 hook.

**Dependencies:** Tasks 16/17/18 (audits clean or fixes merged).

**Edge cases:**
- If any AC remains uncovered AND not deferred — overall verdict is FAIL; pre-deploy hook
  NOT called; loop blocked.
- If Mnemonic MCP is unreachable — fall back to the offline attestation file written by
  Task 08 hook and surface to ops.

**Implementation hints:**
- Use the AC traceability matrix built in Task 18 as the input.
