# Task 06: ruflo install + per-topic cohabitation toggles + MEMORY_NAMESPACE pinning

## Required Skills
Before starting, load: /skill:infrastructure-setup

## Description
Install the ruflo substrate (full CLI) and generate per-topic configuration that pins
the cohabitation toggles and `MEMORY_NAMESPACE` exactly as the per-topic matrix in
tech-spec §2.4 requires. Anchors user-spec AC25–AC28, tech-spec §2.4, D11, D12.

## What to do
- Install ruflo full CLI via the upstream installer; verify with `ruflo --version`.
- Author a global config `~/.fabric/ruflo/global.yml` plus eight per-topic config files
  `~/.fabric/ruflo/topics/{topic}.yml`. Each topic config sets:
  - `autopilot: on|off` per §2.4
  - `aidefence: on|off` per §2.4
  - `rag_memory: on|off` per §2.4
  - `memory_namespace: mnemonic-<topic>` per §2.4
- Tie the topic config into telegram-ai-agent's per-topic engine startup so the engine
  inherits ruflo flags through env or CLI args.
- Validate the resulting matrix against tech-spec §2.4 with a single Python check.

## Acceptance Criteria
- [ ] `ruflo --version` shows the installed full CLI.
- [ ] Eight per-topic config files exist and match the matrix from §2.4 exactly.
- [ ] `ruflo config show --topic core` reflects: autopilot=off, aidefence=off, rag_memory=on, ns=mnemonic-core.
- [ ] `ruflo config show --topic protocol-qa` shows rag_memory=off.
- [ ] `ruflo config show --topic demo-client` shows autopilot=on.
- [ ] Engine spawn in each topic uses the right ruflo flags (verified by env dump from the engine).

**Dependencies:** Task 02 (Telegram bot/topics), Task 03 (master clones — ruflo binds to repo-local config in each).

**Edge cases:**
- ruflo upgrade may rewrite flags — `validate_matrix.py` should run in CI for every loop PR.
- Engine startup must inherit topic flags even when the engine is Codex (demo-client) — wrapper script needed.

**Implementation hints:**
- Reference `MEMORY_NAMESPACE` consistently as `mnemonic-<topic>` to avoid drift.
- Place `validate_matrix.py` under fabric-watchdog (Task 14) too — drift becomes an alert.
