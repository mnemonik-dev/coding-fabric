# Task 08: `fabric/workspace-manager/` — FastAPI service + tests

## Required Skills
Before starting, load: /skill:fastapi-expert

## Description
The central glue service. Per-task git worktrees, per-worktree `.env` materialised from
Vaultwarden, shared sccache, capacity cap = 10, healthcheck. Binds to tailnet IP (set
at deploy time by Ansible). API surface drives both `mnemonic-tg-bridge` (T09 role
deploys) and `swarm-bridge` (T14). Anchors tech-spec §2.5, D9, D10, user-spec AC4–AC7, AC38.

## What to do
- Implement contract from tech-spec §2.5:
  - `POST /worktree`, `DELETE /worktree/{task_id}`, `GET /worktree/{task_id}`,
    `GET /worktrees`, `GET /health`
- Atomic `state.json` persistence
- Vaultwarden client via `bw` CLI, session token loaded via systemd `LoadCredential`
- Sccache mount per-worktree (read-write to shared cache dir)
- All log emissions through `fabric.logs.sanitizer.handler.SanitizedFileHandler` (T07)

## Details
**Files:**
- `fabric/workspace-manager/{main,worktree,vault,state}.py`
- `fabric/workspace-manager/tests/`
- `fabric/workspace-manager/systemd/workspace-manager.service` — `LoadCredential=bw-session:...`
- `fabric/workspace-manager/pyproject.toml`

**Edge cases:**
- Concurrent POST same `task_id` → 409 `already_exists`
- Vault unreachable → 409 `vault_unreachable`, ops alert (via Ansible config + bridge)
- Sccache dir missing → `/health` degraded, but service up
- `task_id` validation — `^[A-Z0-9-]{3,40}$`

**Implementation hints:**
- `git worktree add --detach <base_ref>` to avoid local branch noise
- One per-topic Vaultwarden collection: `mnemonic/topic/<topic>`
- Don't reinvent locking; use stdlib `fcntl` for state.json
