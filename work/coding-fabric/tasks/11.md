## Description
Install molyanov-ai-dev (slash commands + skills) and install the Project Knowledge
guard hook that rejects any ruflo write under `.claude/skills/project-knowledge/references/`
in any worktree. Anchors user-spec AC28, tech-spec D18.

- `roles/molyanov/tasks/main.yml`:
