# Task 09: End-to-end smoke test through full pipeline

## Required Skills
Before starting, load: /skill:pre-deploy-qa

## Description
Drive one representative feature top-to-bottom through the full pipeline: Telegram intent
→ user-spec → tech-spec → tasks → TDD → review → QA → merge. Confirm that all five
attestations are created and linked into a DAG. This is the Phase-2 milestone that proves
the substrate, methodology, attestation, and workspace plumbing are wired correctly.
Anchors user-spec §8.3, AC1–AC16.

## What to do
- Pick a trivially-scoped real feature in `mnemonic-docs` (e.g., fix a typo or add a
  README section).
- From the `docs` Telegram topic, issue the intent.
- Observe the pipeline run autonomously: user-spec drafted, validators run, approval gate
  surfaces in topic, operator approves, tech-spec drafted, task created, TDD executed,
  PR opened, reviewers run, QA passes, merge happens.
- After completion: pull `mnemonic_recall --feature=<id>` and confirm the 5-node DAG.
- Confirm worktree cleanup occurred.

- [ ] One representative `mnemonic-docs` feature merged through the full pipeline.
- [ ] All five molyanov phases visible as Telegram updates in the `docs` topic.
- [ ] `mnemonic_recall --feature=<id>` returns 5 nodes with correct parent chain.
